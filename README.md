# doit

Минималистичный планировщик задач на Vue 3.

## Возможности

- задачи на выбранный день;
- просмотр текущей недели;
- фильтры «Сегодня», «Неделя», «Работа», «Личное»;
- добавление, редактирование и удаление задач;
- отметка выполнения;
- прогресс выбранного дня;
- ближайшие невыполненные задачи;
- хранение задач в `localStorage`;
- адаптивная версия для мобильных устройств;
- горячая клавиша `Ctrl/Cmd + K` для новой задачи.

## Запуск

```bash
npm install
npm run dev
```

Production-сборка:

```bash
npm run build
```
